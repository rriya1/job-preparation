# DSA Interview Prep Strategy

## Topic Order

Recursion (done) → Array/String Patterns → Sliding Window, Two Pointer, Binary Search → Stacks/Queues → LinkedList → Trees → Graphs → DP

Arrays/Strings me patterns sabse cleanly dikhte hain (sliding window, two pointer, prefix sum). Ye patterns phir trees, graphs, DP me bhi recur karte hain — pehle inhe solid karo.

## How to Approach Each New Pattern

1. **Watch ONE short video (10-15 min max)** — pattern-specific, not a full topic lecture. NeetCode or Take U Forward ke pattern videos.
2. **Do 2 worked examples** — step by step trace through with Claude, see HOW the pattern applies.
3. **Solve 2-3 problems on LeetCode** on your own.
4. **Stuck > 20 min?** Come back, do it as a worked example instead of wasting time.

## Notes System — Pattern-First, Not Problem-First

Har pattern ke liye ek file banao (e.g., `sliding_window.md`, `two_pointer.md`). Problem-wise notes mat banao.

Each pattern file should have:

```
## Pattern: [Name]

### When to use:
- [triggers that tell you this pattern applies]

### Template:
[the code skeleton that works for most problems in this pattern]

### Key decisions at each step:
1. [what changes from problem to problem]

### Problems solved:
- LC [number] ([name]) — [one line: what made this problem unique]
```

### Why this works:
- 50 solutions yaad nahi honge, 8-10 patterns yaad honge.
- New problem dekhke question becomes "which pattern?" — not "how do I solve this from scratch?"
- Template se starting point milta h, from-scratch sochna nahi padta.

## Revision System

- Memory resets in 2-3 days, so: **pattern file ko 3 din baad revisit karo.**
- Ek problem try karo bina template dekhe.
- Nahi hua? Template re-read karo, try again. That's it.
- No elaborate revision schedule needed.

## What to Do in Claude Project

For each pattern:
1. Pattern + template explanation
2. 1-2 worked examples (step by step, intermediate states shown)
3. 3-4 LeetCode problems ranked easy → medium
4. Try solo, come back if stuck
5. One "test" problem after a few days
